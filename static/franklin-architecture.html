Design Principles

🔒

Single Writer

Redis lock ensures exactly one race recorder instance owns the model and SQLite. No split-brain.

👁️

Pure View Layers

TUI, GUI, Scoreboard, Driver, Referee — all read-only renderers. They never compute race logic.

📡

Event-Driven

Zero direct IPC. Everything flows through Redis pub/sub. Services can be stopped/started independently.
